
# Avengers Doomsday – Cinematic Fan Website

An unofficial cinematic fan website inspired by the Marvel universe.

## Technologies

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages

## Features

- Cinematic homepage
- Emerald green visual theme
- Animated loading screen
- Floating particle effects
- Character profiles
- Interactive character popup
- Multiverse section
- Cinematic gallery
- Responsive mobile layout

## Project Structure

AvengersDoomsDay/
- index.html
- css/style.css
- js/script.js
- assets/images/

## Run Locally

Open index.html using VS Code Live Server.

## Deployment

Hosted using GitHub Pages.
